Ajustes y API keys

      
Todo funciona sin claves. Las claves desbloquean datos de terceros (backlinks reales, volúmenes de búsqueda, autoridad y visibilidad en IA). Se guardan solo en este navegador y se envían únicamente a tu servidor local. También puedes definirlas en el archivo .env.

      

        Google PageSpeed Insights gratis
        
        Sin clave funciona con una cuota muy limitada. Créala en Google Cloud Console → API "PageSpeed Insights".
      

      

        OpenPageRank gratis
        
        Autoridad de dominio (0-10) basada en enlaces. Regístrate en openpagerank.com.
      

      

        DataForSEO de pago
        

          
          
        

        Backlinks, dominios de referencia, keywords posicionadas, tráfico estimado, volúmenes y dificultad. Se cobra por consulta (céntimos por análisis).
      

      

        Anthropic (Claude) de pago
        
        
        Mide si tu marca aparece y es citada en respuestas de IA con búsqueda web, frente a tus competidores.
